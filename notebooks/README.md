# Tutorial notebooks

One notebook per section of the blog post. Each runs on a free Colab runtime in well under
ten minutes, uses the project's own code (`backend/`), and downloads the pre-computed
artifacts it needs from the `v1.0-artifacts` GitHub release.

| # | notebook | post section | needs GPU |
|---|---|---|---|
| 1 | [tutorial_01_data_and_baselines.ipynb](https://colab.research.google.com/github/juanmigutierrez/generative-recommendation-engine/blob/main/notebooks/tutorial_01_data_and_baselines.ipynb) | Dataset · Popularity · ALS · Scoring the models | no |
| 2 | [tutorial_02_semantic_ids.ipynb](https://colab.research.google.com/github/juanmigutierrez/generative-recommendation-engine/blob/main/notebooks/tutorial_02_semantic_ids.ipynb) | Semantic IDs (trains the RQ-VAE) | recommended |
| 3 | [tutorial_03_generative_retrieval.ipynb](https://colab.research.google.com/github/juanmigutierrez/generative-recommendation-engine/blob/main/notebooks/tutorial_03_generative_retrieval.ipynb) | Generative retrieval (trains a small Transformer, beam search step by step) | yes |
| 4 | [tutorial_04_ranking.ipynb](https://colab.research.google.com/github/juanmigutierrez/generative-recommendation-engine/blob/main/notebooks/tutorial_04_ranking.ipynb) | Ranking (the injection bug, reproduced and fixed) | no |
| 5 | [tutorial_05_evaluation.ipynb](https://colab.research.google.com/github/juanmigutierrez/generative-recommendation-engine/blob/main/notebooks/tutorial_05_evaluation.ipynb) | Both results sections (leave-one-out table with SASRec) | yes |

The notebooks are generated by `_build_tutorials.py` (edit that file, not the .ipynb).
Smoke-test them headlessly with `TUTORIAL_QUICK=1 jupyter nbconvert --execute ...`.

`colab_loo_training.ipynb` is the full GPU training run behind the checkpoints (not a tutorial).
The numbered `0X_*.ipynb` notebooks are the original step-by-step build logs.
